## 执行命令

前端工作目录为 `frontend/`：

```bash
npm test
npm run type-check
npm run build
```

后端工作目录为仓库根目录，使用独立 GOCACHE/GOMODCACHE 和 `GOTOOLCHAIN=local`：

```bash
go build -mod=readonly -o <本地诊断输出>/server.exe ./cmd/server
go test -mod=readonly -json -count=1 ./internal/types ./internal/middleware ./internal/router
```

默认 `CGO_ENABLED=0` 时，除 server 的原生库构建条件错误，测试还在 `gojieba`、`pg_query.Parse/Deparse` 等依赖处编译失败。另以 `CGO_ENABLED=1` 执行 `go test -run '^$' runtime/cgo`，确认缺少编译器；这条是环境探测，不是应用测试。
